Objetivo: evoluir a base existente, não recriar do zero.

Regras:

4. O Perfil deve continuar simples: dados pessoais + objetivo, salvo nova solicitação.
5. A calculadora de economia fica no Início.
6. Substitua gradualmente a persistência JSON por banco de dados e autenticação quando solicitado.
7. Não reescreva o frontend sem necessidade.
8. O nome do produto ainda é provisório e está centralizado na constante APP_NAME em public/js/app.js.
